FR4: Job Event Excecution - P1
Feature Name
           Job Event Excecution
Actor
           Operator
Description
          Membuat event setup, production, idle beserta semua informasi tentang job akun operator dan data mesin
Pre-condition
           Operator harus Login Terlebih dahulu dan masuk Job Excecution Event side bar pada dashboard operator
Post-condition
           	Event Category: Job Execution Event (setup, production, idle) created
Frequency
           	Daily
Functional Flow
1.      Operator login.
2.      Masuk ke Job Execution Event.
3.      Operator memilih
	a.      Get event real time visualization
StatsChart[material consumption(current event paper length, paper waste length, production length, total length)]
GaugeChart[current machine speed]
StatsChart[machine speed statistic]
LineChart[machine speed trend]
StateTimelineBar[event timeline]
PieChart[event ratio]
StatsChart[run and stop duration]

a.      Create Setup Event  to Machine
Card[Current Active Job Execution Event] -> Button[Create Setup Event] -> DialogCenter[Create Confirmation] -> Button[Yes] / Button[No]
b.      Create Production Event  to Machine
Card[Current Active Job Execution Event] -> Button[Create Production Event] -> DialogCenter[Production Confirmation] -> Button[Yes] / Button[No]
c.      Create Idle Event  to Machine
Card[Current Active Job Execution Event] -> Button[Create Idle Event] -> DialogCenter[Idle Confirmation] -> Button[Yes] / Button[No]
d.      End Active Event  to Machine
Card[Current Active Job Execution Event] -> Button[EndEvent] -> DialogCenter[End Confirmation] -> Button[Yes] / Button[No]
Business Rules
1.      Job Execution Event hanya bisa dibuat kalau ada job yang di assign di mesin.
2.      Dalam 1 waktu hanya boleh ada 1 aktif job execution event.
3.      Job Execution Event sifatnya rolling, jika saat ini event yang aktif adalah event A lalu operator membuat event B, maka event A otomatis End(end time event A terdefinisi dan start time event B = end time event A)
